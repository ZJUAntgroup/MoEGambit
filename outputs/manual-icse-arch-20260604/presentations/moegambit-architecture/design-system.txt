Slide size: 1280x720.
Background: warm near-white paper (#F8F7F2), no heavy shadows.
Typography: Aptos Display for claim title; Aptos for labels; Aptos Mono only for code-like terms.
Palette:
- Ink: #18202B for primary text.
- Muted text: #5B6472.
- Contract blue: #315D9B.
- Hybrid green: #1F7A4D.
- Restart red: #B34B3D.
- Checkpoint violet: #7257A7.
- Soft fills: low-saturation tints only.
Diagram grammar:
- One left-to-right causal flow.
- Green path means hybrid fast path; red path means checkpoint restart fallback; blue means contract/control plane.
- Boxes only indicate real state boundaries, guards, or path choices.
- Labels stay short and direct; no bullets longer than one line.
Connector grammar:
- Thin semantic connectors with explicit arrowheads rendered as text glyphs; no decorative arrows.
Footer grammar:
- Quiet note only when needed.
Banned motifs:
- Dense pipeline micro-grids, nested cards, large bullet blocks, ornamental icons, unofficial logos.
