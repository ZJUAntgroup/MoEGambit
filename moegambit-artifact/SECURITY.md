# Security Policy

Please do not disclose private security reports through public issues.

If you find a vulnerability in MoEGambit-specific code or in the artifact
packaging, use GitHub private vulnerability reporting if it is enabled for the
repository, or contact the repository maintainer privately.

For vulnerabilities in upstream Megatron-LM or its dependencies, follow the
upstream project's security process and include the affected upstream version or
commit when reporting the issue here.
